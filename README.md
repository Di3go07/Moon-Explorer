# 🌕 MOON EXPLORER
### NASA Space Apps Challenge 2026

*Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars*

> Explore the Moon. Discover the forgotten. Remember the legacy.

## 🌌 About the Project

Since the 1960s, NASA has left hardware across the solar system — on the Moon, on Mars, and in deep space. From rovers and instruments that completed their scientific missions to probes still traveling away from Earth, this hardware varies widely in both its purpose and current level of functionality.

The **Moon Explorer** project aims to tell the stories of these forgotten objects in other worlds, highlighting the remarkable legacy they have left on Earth.

Through a three-dimensional replica of the Moon and its artifacts, students and space exploration enthusiasts can discover forgotten equipment, learn about its missions, and understand the importance of its contributions to science.

Dense scientific information and academic texts are transformed into an unforgettable journey through space and imagination.

## 🛰️ 3D Models

The three-dimensional models of the Moon and its space artifacts were created using Blender.

Due to GitHub storage limitations, the 3D files and some visual assets are not available directly in the repository.

To access them, visit the shared Google Drive folder:

The expected directory structure is:

```text
moon-explorer/
├── assets/

│   ├── ...

```

Make sure all files are placed in the paths expected by the project to ensure that models and images render correctly.

## 🌐 Interactive Experience

Moon Explorer offers an exploration experience in which users can navigate a three-dimensional representation of the Moon and discover the equipment left behind on its surface.

When selecting an artifact, users are presented with an information card containing:

- **Identification:** the equipment's name and associated mission.
- **Technical Specifications:** information about its characteristics and functionality.
- **Historical Context:** details about its journey, from launch and landing to the end of its mission.
- **Scientific Legacy:** discoveries, contributions, and the impact of its work on space exploration.

In addition to the 3D experience, the project incorporates **accessibility features and multilingual support**, making the content more inclusive and expanding access to knowledge.

## 🚀 Running the Project

To run Moon Explorer locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone <REPOSITORY_URL>
   ```

2. **Navigate to the project directory:**

   ```bash
   cd moon-explorer
   ```

3. **Download the 3D models and visual assets** available in the Google Drive folder.

4. **Create an `assets` folder** in the project's root directory and place all downloaded files inside it.

5. **Open the project** in your preferred code editor.

6. **Run the website:** open the `index.html` file in your browser or use a local development server extension, such as Live Server (recommended).

That's it! You're ready to explore the Moon and discover the stories of the machines that helped humanity reach further into space.
